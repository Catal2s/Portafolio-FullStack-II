# Planificación del Portafolio Profesional

## Objetivo

Presentar mi identidad profesional y evidenciar los aprendizajes de la primera unidad de la asignatura Desarrollo FullStack II, mediante un sitio web personal desarrollado individualmente con HTML5, CSS3 y JavaScript.

## Público objetivo

Profesores de la asignatura que evaluarán el portafolio, además de posibles empleadores, reclutadores y compañeros de la carrera.

## Secciones

1. **Inicio**: presentación principal, nombre y enlaces a las demás secciones (Habilidades, Proyectos, Contacto).
2. **Sobre mí**: formación académica, intereses y objetivo laboral.
3. **Habilidades**: conocimientos técnicos (Python, Java, SQL, Git, etc.) y habilidades blandas.
4. **Proyectos**: VETTsafe y Evaluación 3 - Desarrollo Fullstack.
5. **Contacto**: formulario validado con JavaScript y enlace al perfil de GitHub.

## Tecnologías

- HTML5 semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 externo con Flexbox, Grid y media queries (diseño adaptable)
- JavaScript para validación de formularios con mensajes de error
- Git y GitHub para control de versiones y despliegue público (GitHub Pages)

## Requisitos principales

- Estructura semántica de HTML5 válida y navegación funcional.
- Diseño personalizado, consistente y adaptable a computador, tablet y teléfono.
- Validaciones del formulario con mensajes de error claros y en contexto.
- Repositorio remoto con commits progresivos, claros y descriptivos.
- Portafolio desplegado públicamente y operativo al momento de la entrega.
