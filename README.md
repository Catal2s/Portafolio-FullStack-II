# Portafolio Profesional — Javier Cataldo Barrera

Portafolio personal desarrollado como parte de la Evaluación Parcial 1 de la asignatura Desarrollo FullStack II (DSY1104). El sitio presenta mi identidad profesional como estudiante de Ingeniería en Informática: habilidades, proyectos realizados durante la carrera y una vía de contacto.

## Objetivo

Mostrar de forma clara y profesional mis habilidades técnicas y proyectos desarrollados, sirviendo como carta de presentación ante posibles empleadores o instituciones de práctica.

## Tecnologías utilizadas

- **HTML** semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS** externo, con Flexbox, Grid y media queries para diseño responsivo
- **JavaScript** para validación de formularios con mensajes de error

| Contacto | Formulario validado con JavaScript y enlace a GitHub |

## Validaciones del formulario

El formulario de contacto valida en el cliente:

- Nombre completo obligatorio (mínimo 3 caracteres)
- Formato de correo electrónico válido
- Mensaje obligatorio con mínimo 10 caracteres

Cada error se muestra en contexto, junto al campo correspondiente.

## Cómo verlo localmente

1. Clonar este repositorio: `https://github.com/Catal2s/Portafolio-FullStack-II.git`
2. Abrir `index.html` en el navegador (usar extensión Live Server).
